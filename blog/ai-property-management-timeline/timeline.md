## FAQ

### What is MCP (Model Context Protocol)?

MCP is an open standard that Anthropic introduced in November 2024 and OpenAI adopted in March 2025. It lets AI assistants like Claude and ChatGPT connect to outside software through a standard connector. For a property manager, an MCP server from your property management software means an AI assistant can look up, and sometimes act on, your live data, limited to what the person who connected it is allowed to see and do.

### What is the difference between an API and an MCP connector?

An API is the general-purpose connection developers use to link one piece of software to another, and it usually takes a developer to use. An MCP connector is built for AI assistants: it packages a vendor's data and actions into tools an assistant can find and use on its own, so a non-technical user can connect Claude or ChatGPT in a few clicks. Many MCP servers are built on top of the vendor's API, and an MCP can expose less, or occasionally more, than the API does.

### Can an AI agent use property management software that has no API?

Often, yes. Computer-use agents (Claude computer use, ChatGPT agent, Claude in Chrome, Chrome auto browse and others) work through the normal screen: they log in, read the page, click and type the way an office worker would, so they don't need the vendor to offer an API or MCP connector. The trade-offs are real: they are slower than an API, they can break when a screen changes, they often need a person for logins and two-factor codes, and using one may conflict with your software's terms of service. In August 2026 a federal appeals court ruled, in Amazon's case against Perplexity, that when a user directs an agent, it is the user who is accessing the site, but that case is still going and this is not legal advice. Check your agreement with your vendor before relying on one.

### What counts as an event on this timeline?

Whole new generations of frontier AI models, plus releases that drove major usage; personal AI agents and computer-use agents; and, for property management software and vendors, API launches and openings, MCP servers and AI connectors, notable AI product launches, funding, acquisitions and access cut-offs. Minor point releases are left out. General business tools (accounting, phones, banks) appear only for API launches and Claude or ChatGPT connectors, not for their general in-app AI features.

### How is a launch confirmed?

An event is listed as shipped only when there is evidence that customers can actually use it: a company announcement that it is available, help-center documentation, or pricing. Thought-leadership articles and roadmap mentions do not count. Announcements without real availability are listed under "Announced, not shipped yet" until they ship. When only an approximate date is known, the date reads "By [month]".
