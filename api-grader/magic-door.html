The MCP step

An official MCP server moves the final grade up one step on the scale, once. It applies even past a gate's limit, and the score moves to the bottom of the new step's range.

C+ (77) → B- (80) B+ (88) → A- (90) A (94) → A+ (97)

The bottom line.

MagicDoor's API reaches almost everything in the product. The published documentation shows how to read and change leases, tenants, rent and deposit ledgers, bills, bank reconciliations, owner distributions, and work orders, and any customer can create tightly limited keys at no extra cost. The biggest limitation is that MagicDoor publishes this as the interface its own apps use, not as a supported product, and its docs say the API can change at any time without notice. The published documentation also shows no way to be alerted when data changes and no protection against a retried payment post being recorded twice. MagicDoor is not a bank: payments run through third-party processors, the bank accounts are your own and link through Plaid, and its trust-accounting features are reachable through the API. Build on it for scheduled syncs, reporting, AI assistants, and carefully supervised write automations, and test writes carefully, because the docs offer no published sandbox.

What it is: MagicDoor is AI-enabled property management software with built-in trust accounting, not a bank, with the API and MCP server included. You still need your own bank accounts (linked through Plaid), MagicDoor's third-party payment processors to move money, and scheduled re-checks to catch changes.

What works

  • API and MCP access included at no extra cost, with no gated tiers.
  • Customers create their own API keys, with no sales call or approval.
  • 967 documented endpoints, each with a cURL example.
  • Read and change leases, tenants, and rent and deposit ledgers.
  • Bills, bank reconciliations, owner distributions, and work orders are all reachable.
  • Reverse ledger entries, record returned payments, and release security deposits.
  • Trust accounting features, like deposit ledgers and period locks, reachable through the API.
  • Fine-grained keys limited to exactly what each tool needs, revocable instantly.
  • Full API docs in AI-ready formats, including llms-full.txt and Markdown pages.
  • Official read-only MCP server lets AI assistants answer portfolio questions.

What to watch

  • The published documentation shows no webhooks or changed-since filter.
  • MagicDoor says the API can change at any time without notice.
  • No version number and no deprecation window.
  • The published documentation shows no protection against double-posting a retried payment.
  • The published documentation shows no protection against overwriting another tool's edits.
  • No published test environment; the docs say calls hit production.
  • No public status page, incident history, or SLA.
  • IDs change type between endpoints, and money is a plain number.
  • Error shapes vary, and stable error codes exist on only a few endpoints.
  • No OpenAPI file, official code library, or API changelog.
