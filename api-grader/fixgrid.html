The MCP step

An official MCP server moves the final grade up one step on the scale, once. It applies even past a gate's limit, and the score moves to the bottom of the new step's range.

C+ (77) → B- (80) B+ (88) → A- (90) A (94) → A+ (97)

The bottom line.

FixGrid is a maintenance system that runs beside your PMS. It is not a PMS or a bank. Its API is free on every plan and well built: you can pull your maintenance data out and push in the core work-order actions (create, assign, complete, cancel, and reopen tickets), plus record notices and move-ins. Its biggest strength is careful engineering, with read-only and per-action keys, safe retries, overwrite protection, documented change syncing, signed webhooks, and AI-friendly docs. Its biggest limit is reach: the published documentation shows no way to schedule appointments, add photos, read notes, add or edit vendors, read residents, or handle estimates, invoices, or owner approvals, and there is no API sandbox or "sign in with FixGrid" option. You still need your PMS for leasing, residents, and accounting, and today the two share data by file, not live sync.

What it is: FixGrid is maintenance-management software (a CMMS) built for multifamily operators, not a PMS or a bank. You still need your PMS for leasing, residents, and accounting, and today data moves between them by rent-roll file and CSV, not live sync.

What works

  • API and signed webhooks included on every plan, with no extra fee
  • Admins create API keys themselves, with no sales call or approval
  • Create, assign, complete, cancel, and reopen work orders through the API
  • Read-only and per-action keys limit what each tool can do
  • Every write takes an idempotency key, so retries never create duplicates
  • Overwrite protection stops one edit silently replacing another on a ticket
  • Change syncing on every object list except staff
  • Signed, retried webhooks for new tickets, status changes, and assignments
  • Clear error codes and a support-ready request id on every response
  • Public OpenAPI spec and one-file AI-readable docs, no login needed

What to watch

  • The published documentation shows no appointment scheduling on work orders
  • The published documentation shows no photo upload, which blocks photo-required close-outs
  • Ticket notes can be added but cannot be read back through the API
  • The published documentation shows no way to add, edit, or deactivate vendors
  • The published documentation shows no resident records to read
  • The published documentation shows no estimates, invoices, or owner approvals
  • The published documentation shows no API sandbox, so testing uses a real account
  • No "sign in with FixGrid" option, so connecting a tool means sharing a key
  • Only 90 days' notice for breaking changes, and one change skipped it
  • No rate-limit headers on live responses, so you can't see the limit coming
