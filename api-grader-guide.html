How to Run the PM API Grader

A step-by-step guide for anyone helping test a platform we don't have direct access to.

Thanks for helping out. Property managers should be able to get their own data out of the software they pay for, and right now some platforms make that easy and some make it nearly impossible. We're grading the APIs of the major PM platforms and point solutions to find out which is which, and we can't personally test every product ourselves. That's where you come in.

This takes about 15 to 20 minutes. Here's exactly how to do it.

The process

Five steps, start to finish.

1

Download the grading file

Grab the .md file above. This is the exact prompt we use to grade every platform: same file, same criteria, every time. Nothing hidden, nothing platform-specific baked in. That's on purpose. It's how we keep this fair.

2

Open Claude Code

If you don't already have it set up, go to claude.com/claude-code and follow the install instructions. If you're already using Claude Code for anything else, you're good to go.

3

Point it at the platform's API docs

Open Claude Code and give it two things:

  1. The .md grading file you downloaded
  2. A link to (or copy of) the platform's public API/developer documentation

Ask it to run the grading criteria in the .md file against the documentation you've provided.

4

Let it run and review the output

Claude will work through each grading category and return a score with reasoning. Skim it. If something looks off or the documentation was incomplete, note that. We'd rather know than get a false score.

5

Submit your results

Drop in:

  • Platform name
  • The completed grading output
  • Your name and company (optional, totally fine to submit anonymously if you'd rather not be named as a contributor)
