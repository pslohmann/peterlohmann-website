Tester Guide:

Property Management API Grader

Help find out which PM platforms actually let you get to your own data.

Property managers should be able to get their own data out of the software they pay for, and right now some platforms make that easy and some make it nearly impossible. I'm grading the APIs of the major PM platforms and point solutions to find out which is which, and I can't personally test every product myself.

This takes about 15 to 20 minutes. You'll never be named in the published report, so there's no risk of blowback from a vendor. Click below to get started.

Updated for methodology v1.2. You collect the evidence, and I do the grading.

Methodology v1.2

Five steps, start to finish.

1

Download the grading file

Download the .md file here. It's the same file I use for every platform, with nothing tailored to any one of them. That's how I keep this fair.

2

Open Claude Code

If you don't already have it set up, go to claude.com/claude-code and follow the install instructions. If you're already using Claude Code for anything else, you're good to go.

Important: Set the model to Claude Opus 5.5 and reasoning effort to High. Scores from smaller models or lower effort settings aren't comparable, so I can't use them.

3

Start a fresh session and point it at the API

Start a brand new Claude Code session, and give it three things:

  1. The .md grading file you downloaded
  2. A link to (or copy of) the platform's API/developer documentation
  3. An API key for the platform's account

Ask it to run the test, and tell it you have access to the live API and will provide the credentials.

Click to see the prompt I use

This is a fresh session. Ignore all previous API grader runs and data and treat this as a clean room. Use only the attached methodology-v1.2.md, anything else I attach here, the vendor's public materials, and the API; don't read other files on this computer. Run the methodology against [PLATFORM] as the tester: do the evidence session only, and stop once the evidence packet is frozen. Don't score it. Testing is read-only: make no call that creates, changes, or deletes data. My API credentials: [PASTE KEY]

Save the frozen packet as one Markdown file named [PLATFORM]-evidence-packet-[today's date as YYYY-MM-DD].md, send it to me in this chat, and tell me where it's saved. Don't leave any other files behind, and don't create a CLAUDE.md or README. The packet must let a grader work without opening any links or calling the API. Include:

  • the packet ID and freeze date
  • the frozen coverage table
  • every source with its URL, evidence label, and the saved text of the parts that matter
  • every standard location checked and what was found
  • the evidence-amendment log
  • every live test, with the request sent and the response received

Leave out the API key, any personal or tenant data, and your provisional marks.

If you're testing more than one platform, start a separate session for each and repeat the clean-room line in the prompt, so one platform's results can't affect the next.

Two things make the results noticeably more accurate. First, a screenshot of the screen where you create API keys. Claude often can't tell what kinds of keys exist (read-only or read-write, or whether you can create more than one), and several checks depend on it. Second, the API documentation itself if you can download it, not just a link.

4

Let it run

The session reads the platform's docs, runs a few read-only tests, and saves one evidence packet file. It won't ask you anything, and it won't give you a score. I grade every packet myself, three separate times.

Skim the final output. If something looks off, or the documentation was incomplete, tell me. I'd rather know than publish a false score.

5

Submit your results

Drop in:

  • Your name and email (so I can follow up if I have a question or need a re-run; never published)
  • Platform name
  • The evidence packet (.md file)

You'll never be named in the published report, and no vendor will know the results came from you. I only ask for your name so I can follow up with a question or ask for a re-run. That stays between us.
